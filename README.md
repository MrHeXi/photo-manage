# Photo Manage

一个优先适配 Windows 的照片 / 文件整理去重桌面应用。

## 适合的使用场景

- 多个硬盘、移动硬盘、备份盘里都有重复照片
- 照片、视频、文档混在一起，想分门别类整理
- 想先看重复关系，再决定保留哪份
- 想把保留后的文件集中整理到自己的资料库

## 当前已完成功能

- 支持一次添加一个或多个扫描目录
- 支持完全重复文件检测：文件大小 + SHA-256
- 支持图片相似检测
- 支持视频预览
- 已安装 `ffmpeg` 时支持相似视频检测
- 支持图片 / 视频预览
- 支持“保留最高质量 / 最新修改 / 最大文件”默认保留策略
- 支持手工勾选保留项
- 支持记住最近一次扫描结果
- 支持记住你在重复分组中的手工保留选择
- 支持把未勾选文件移动到目标目录
- 支持把未勾选文件移动到 Windows 回收站
- 支持操作记录与撤销移动
- 支持扫描历史查看与清空
- 支持 AI 图片判断，兼容 OpenAI 风格 `chat/completions` 接口
- 支持单张图片 AI 判断
- 支持当前重复分组批量 AI 判断
- 支持 AI 结果筛选与 CSV 导出
- 支持整理中心
- 支持把文件按“照片 / 视频 / 文档 / 其他”分流到不同目标目录
- 支持“仅整理重复组中的保留文件”
- 支持磁盘 / 目录树视图浏览重复文件
- 支持从目录树直接定位到原始重复分组
- 支持从目录树直接加入整理预览

## 界面说明

应用当前主要有这些区域：

- 左侧：扫描目录、目标目录、相似阈值、保留策略、扫描按钮
- 中间：重复分组 / 磁盘目录 两种浏览方式
- 右侧标签页：
  - 整理中心
  - 重复处理
  - 操作记录
  - 扫描历史
  - AI 判断

## 推荐工作流

### 1. 重复清理

1. 添加要扫描的一个或多个目录
2. 点击“开始扫描”
3. 在“重复分组”或“磁盘目录”里查看重复关系
4. 在“重复处理”里勾选你要保留的文件
5. 选择处理方式：
   - 移动到目标目录
   - 移动到回收站
6. 点击“移动未勾选项”

### 2. 按目录排查

如果你更关心“哪个盘、哪个目录最乱”，可以切到“磁盘目录”模式：

1. 先按盘符、目录、文件浏览
2. 看下方表格里的关联目录和关联分组
3. 点击“定位首个分组”跳回原始重复分组
4. 或点击“加入整理预览”，直接把当前目录里的文件送去整理中心

### 3. 集中整理保留文件

在“整理中心”里：

1. 配置四类目标目录
   - 照片目标目录
   - 视频目标目录
   - 文档目标目录
   - 其他文件目录
2. 如果只想整理你最终保留的文件，勾选“仅整理重复组中的保留文件”
3. 点击“生成整理预览”
4. 检查建议目标路径
5. 点击“执行整理预览”

## 关于“保留的文件会保留在哪里”

保留文件默认不会被移动。

- 在重复处理里，勾选的文件表示保留在原位置
- 未勾选的文件才会按你的处理方式移动

如果你后续想把保留文件统一归档：

- 去“整理中心”
- 勾选“仅整理重复组中的保留文件”
- 生成并执行整理预览

这样才会把你保留下来的文件集中整理到目标资料库中。

## 关于“整理中心”的当前行为

整理中心当前是“按分类路由”的版本：

- 照片 -> 照片目标目录
- 视频 -> 视频目标目录
- 文档 / 压缩包 -> 文档目标目录
- 其他文件 -> 其他目标目录

当前这一版还没有做非常复杂的规则系统，比如：

- 按相机型号分照片库
- 按文件名关键词分流
- 按原始目录关键词分流

但基础的跨盘归集、分类整理已经能用了。

## AI 判断说明

“AI 判断”页支持配置兼容 OpenAI 风格的视觉模型接口。

需要填写：

- API 地址，例如 `https://api.example.com/v1`
- 模型名，例如 `gpt-4o-mini`
- API Key

当前内置了这些预设入口：

- OpenAI
- DashScope
- DeepSeek
- Moonshot
- Zhipu
- 自定义

支持的操作：

- AI 判断当前图片
- AI 判断当前分组
- 按分数筛选低质量图片
- 导出 AI 结果 CSV

## 扫描历史与恢复

- 扫描历史页可查看最近扫描过的文件记录
- 最近一次扫描得到的重复分组会单独保存
- 重启应用后，会尝试恢复最近一次扫描结果
- 清空扫描历史时，会同时清除：
  - 扫描历史
  - 文件指纹缓存
  - 最近一次保存的扫描会话

## 操作记录与撤销

“操作记录”页会记录：

- 移动到目标目录
- 移动到回收站
- 整理中心执行的移动

支持撤销的是普通移动操作。  
移动到回收站的文件，需要在 Windows 回收站里恢复。

## 安装与运行

### 方式一：本地运行

1. 创建虚拟环境

```powershell
py -3.10 -m venv .venv
```

2. 激活虚拟环境

```powershell
.\.venv\Scripts\Activate.ps1
```

3. 安装依赖

```powershell
pip install -r requirements.txt
```

4. 启动应用

```powershell
python -m photo_dedupe
```

也可以直接运行：

```powershell
.\run.ps1
```

### 方式二：打包为 Windows EXE

先安装 PyInstaller：

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
```

直接运行打包脚本：

```powershell
.\build.ps1
```

打包完成后可执行文件位于：

```text
dist\PhotoManageGPT\PhotoManageGPT.exe
```

## 视频相似检测说明

完全相同的视频文件会通过 SHA-256 自动识别。

如果要识别“内容相似但文件不同”的视频，需要系统里安装 `ffmpeg`：

```powershell
ffmpeg -version
```

安装后，应用会抽帧生成视频指纹用于相似检测。  
未安装 `ffmpeg` 时不会影响其他功能。

## 默认数据位置

本机数据库默认保存在：

```text
%LOCALAPPDATA%\PhotoManageGPT\photo_manage.db
```

默认重复文件移动目标目录是：

```text
桌面\PhotoManageGPT_重复文件
```
