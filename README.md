# Photo Manage

一个优先适配 Windows 的照片 / 文件整理去重桌面应用。它的目标不是只“找出重复文件”，而是帮你在多块硬盘、移动盘、备份盘之间安全地看清重复关系、选择保留版本、批量处理副本，并把真正要留下的文件整理到自己的资料库。

## 核心能力

- 多目录扫描：支持一次添加一个或多个扫描目录。
- 新手向导：把添加目录、保护目录、扫描、保留规则、整理预览和方案保存串成可检查的流程。
- 安全试用样例：新手向导和帮助菜单可一键创建演示目录，自动加入扫描目录并把主资料库设为保护目录，便于先练习完整流程。
- 扫描目录安全检查：开始扫描前会阻止整盘根目录、Windows / 程序目录、处理目标目录、未连接或不可读取目录，父子目录重复选择和空目录会提示确认。
- 完全重复检测：按文件大小 + SHA-256 精确识别。
- 相似图片检测：支持相似阈值、仅同宽高比、仅同分辨率过滤。
- 图片预览详情：选中图片时显示大小、尺寸、拍摄时间、相机型号、保护目录状态和完整路径。
- 图片并排对比：当前重复组可打开大图对比窗口，按推荐保留、保护目录和图片质量排序展示。
- 相似视频检测：系统安装 `ffmpeg` 后可抽帧生成视频指纹。
- 保护目录：可把主资料库、相册库、工作目录设为保护目录，批量处理会跳过这些目录内文件。
- 内置整理模板：提供家庭照片整理、多盘照片汇总、工作文档归档、聊天缓存复核等场景，套用后只替换规则和目标目录，不会移动文件。
- 整理方案：可保存常用扫描目录、保护目录、保留策略、批量规则、相似图片选项和分类整理目标，之后一键加载复用。
- 批量保留规则：支持保护目录优先、最高质量、最大文件、最新修改、最高分辨率、路径最短、路径最深、非副本命名。
- 推荐保留原因：重复文件表会标出建议保留、保护目录跳过、手动保留或可处理状态。
- 分组摘要：点开重复分组后显示类型、文件数、占用空间、预估可省、涉及磁盘/目录和推荐保留文件。
- 快速定位文件：在重复处理页可直接打开选中文件所在文件夹，操作记录页也可打开当前位置或原目录。
- 安全处理确认：处理当前筛选结果前会显示风险等级、分组数、保留数、待处理数、预估空间、保护目录跳过数、涉及目录和回收站提醒。
- 处理结果报告：移动、回收站和整理执行后会显示计划处理数、实际完成数、跳过数、空间统计、涉及目录和恢复方式，并自动保存包含逐文件明细的文本报告。
- 目标空间检查：移动到目标目录前会显示目标磁盘可用空间，空间不足时会提高风险提示。
- 扫描缓存与历史：重启后会恢复最近一次扫描结果；扫描历史可双击加载、删除单条任务、按时间/空间/分组数排序筛选。
- 过程可见性：扫描和历史恢复会显示当前阶段、已处理数量和百分比，减少长任务卡死感。
- 支持诊断信息：健康诊断页可查看并复制版本、程序路径、数据库路径、日志路径、报告目录、运行环境和历史缓存状态，便于反馈启动或缓存问题。
- 磁盘目录视图：按磁盘 / 目录树查看重复文件分布，并可定位回原始重复分组。
- 整理中心：按照片 / 视频 / 文档 / 其他分流到不同目标目录，支持仅整理重复组中的保留文件。
- 整理预览状态：预览表显示文件状态和大小；执行整理前显示文件总数、总大小、分类数量、目标目录、来源目录和跳过提醒。
- AI 判断：兼容 OpenAI 风格 `chat/completions` 视觉模型 API，支持单张图片、当前分组批量分析、低分筛选和 CSV 导出。
- 操作记录：记录移动和回收站操作；普通移动支持撤销，并可按动作、状态和路径关键词筛选。
- 品牌外观：内置应用图标，覆盖窗口、任务栏和打包后的 `PhotoManageGPT.exe`。

## 推荐工作流

### 1. 安全去重

1. 第一次使用可先打开“新手向导”，按当前状态查看下一步。
2. 点击“添加文件夹”，选择一个或多个扫描目录。
3. 如果某个目录是你的主资料库，选中它后点击“设为保护目录”。
4. 根据需要设置图片相似阈值，以及“仅同宽高比 / 仅同分辨率”。
5. 点击“开始扫描”。
6. 在中间的“重复分组”或“磁盘目录”查看重复关系。
7. 在“重复处理”页选择批量保留规则，先点“预览应用规则”，确认后点“应用到当前筛选结果”。
8. 选择“移动到目标目录”或“移动到回收站”。
9. 点击“处理当前筛选结果”，检查确认摘要后再执行。
10. 处理完成后查看处理结果报告；需要核对或恢复时进入“操作记录”。

### 2. 多盘整理

1. 在“磁盘目录”视图中按盘符和目录查看哪些目录参与了重复。
2. 选择目录后可“定位首个分组”，回到重复分组明细。
3. 也可以点击“加入整理预览”，把当前目录中的候选文件送入整理中心。
4. 在“整理中心”选择归档方式，并配置照片、视频、文档、其他文件的目标目录。
5. 点击“预览整理结果”，确认来源和建议目标后再执行；修改设置会自动清除旧预览。

### 3. 保存常用整理方案

- “整理中心”的场景模板可以先选择一个常见场景并点击“套用模板”，软件会保留当前扫描目录和保护目录，只替换保留规则、归档方式、相似图片选项和目标目录。
- 套用模板不会移动、回收或删除任何文件；确认合适后可继续点击“保存方案”，把它保存成自己的常用方案。
- 在“整理中心”的整理方案区域点击“保存方案”，可以把当前扫描目录、保护目录、重复文件移动目标、保留策略、批量规则、相似图片选项、归档方式和目标目录保存成命名方案。
- 以后选择方案后点击“加载方案”，会恢复这些配置，但不会移动、回收或删除任何文件。
- 不再需要的方案可点击“删除方案”，这只删除方案配置，不会影响扫描历史和操作记录。

### 4. 恢复旧扫描结果

- 软件启动时会尝试加载最近一次扫描缓存。
- 如果历史结果很多，默认先加载前 500 组，界面会显示 `已恢复 N/M 组`。
- 点击“继续加载更多”可以继续加载，无需重新扫描。
- “扫描历史”页可以查看历史扫描任务，双击任务即可加载当时的重复分组。
- “导出任务记录”会导出当前筛选下的扫描任务列表，包含中文时间、占用空间、预估可省和原始数值；“导出文件缓存”会导出已缓存的文件指纹明细。

### 5. 反馈启动或缓存问题

- 打开“健康诊断”页可以查看数据库、日志、视频指纹、历史缓存和运行环境状态。
- 点击“复制诊断信息”可复制版本、程序路径、数据库路径、日志路径、报告目录、系统环境和历史缓存状态；这段信息不包含 AI API Key。
- 点击“导出诊断报告”会保存同样的诊断文本，适合在无法直接复制时发送。

### 6. 核对和恢复操作记录

- “操作记录”页会显示最近的移动和回收站操作。
- 可以按“全部动作 / 移动 / 回收站”和“全部状态 / 可撤销 / 已撤销 / 不可撤销”筛选，也可以输入路径关键词查找记录。
- 点击“导出操作记录”会导出当前筛选结果，包含中文动作、状态、可读时间和原始时间戳，便于用 Excel 核对。
- 每次处理或整理完成后，软件会在应用数据目录的 `reports` 文件夹保存一份文本报告；可在“操作记录”页或“健康诊断”页点击“打开报告目录”查看。
- 普通移动记录可点击“撤销选中移动”恢复到原位置；如果原位置已有同名文件，会自动改名避免覆盖。
- 也可以点击“撤销当前筛选移动”批量撤销当前筛选结果中的普通移动记录；回收站记录和已经撤销的记录会自动跳过。
- 点击“打开当前位置”可定位移动后的文件或回收站记录的原目录；点击“打开原目录”可回到文件原来所在目录。
- 移动到回收站的文件需要在 Windows 回收站中恢复，本软件只记录这类操作，不直接替系统回收站撤销。

## 重要安全规则

- 勾选的文件表示保留。
- 未勾选的文件才会被“处理当前筛选结果”移动或送入回收站。
- 批量处理前会显示风险等级和风险提示；移动到回收站后需要在 Windows 回收站中还原，本软件不会直接撤销回收站操作。
- 移动到目标目录前会检查目标磁盘剩余空间；如果空间不足，请先换目标目录或释放磁盘空间。
- 开始扫描前会阻止整盘根目录、系统目录、整理/移动目标目录、未连接或不可读取目录，避免卡死、权限错误和反复扫描已处理文件。
- 保护目录内文件不会被批量移动或回收。
- 每个重复分组必须至少保留一个文件，否则会阻止批量处理并提示定位。
- 默认不做永久删除。回收站操作需要在 Windows 回收站中恢复。
- 整理中心会自动跳过保护目录和整理目标目录，避免边整理边重复扫描刚移入的文件。

## 保留规则说明

- 保留保护目录内文件：适合主资料库优先。
- 保留最高质量：按分辨率、大小、修改时间综合判断。
- 保留最大文件：适合压缩图和原图混在一起的场景。
- 保留最新修改：适合文档或最近整理过的目录。
- 保留最高分辨率：适合照片。
- 保留路径最短：适合保留目录结构更干净的一份。
- 保留路径最深：适合保留已经分类到相册或项目目录的一份。
- 保留非副本命名：会避开 `copy`、`副本`、`重复`、`微信缓存` 等明显副本命名。

## AI 判断

“AI 判断”页支持兼容 OpenAI 风格的视觉模型接口。

需要填写：

- API 地址，例如 `https://api.example.com/v1`
- 模型名，例如 `gpt-4o-mini`
- API Key

API Key 输入框默认隐藏显示，需要核对时可勾选“显示 Key”。配置只保存在本机数据库中。

填写后可以先点击“检查 AI 配置”。这个检查只在本机验证地址格式、模型名、API Key 是否缺失，以及最终会请求的 `chat/completions` 端点，不会联网验证 Key 是否有效。

内置入口：

- OpenAI
- DashScope
- DeepSeek
- Moonshot
- Zhipu
- 自定义

AI 判断适合用于照片质量评分和保留建议，但不作为自动删除的唯一依据。

## 数据位置

本机数据库默认保存在：

```text
%LOCALAPPDATA%\PhotoManageGPT\photo_manage.db
```

也可以在“健康诊断”页点击“打开数据目录”或“打开日志目录”，直接定位数据库、日志和排障文件所在位置。

默认重复文件移动目标目录：

```text
桌面\PhotoManageGPT_重复文件
```

打包后的可执行文件：

```text
dist\PhotoManageGPT\PhotoManageGPT.exe
```

## 本地运行

创建虚拟环境：

```powershell
py -3.10 -m venv .venv
```

安装依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

启动应用：

```powershell
.\.venv\Scripts\python.exe -m photo_dedupe
```

如果历史缓存异常导致启动卡住，可以使用安全模式跳过历史恢复：

```powershell
.\.venv\Scripts\python.exe -m photo_dedupe --safe-mode
```

也可以运行启动烟测，软件会在临时数据目录和安全模式下初始化主窗口后立即退出，用于确认当前环境不会出现无界面后台进程：

```powershell
.\.venv\Scripts\python.exe -m photo_dedupe --startup-smoke-test
```

如果关闭窗口后任务管理器中仍有 `PhotoManageGPT.exe`，可以先结束该进程，再用安全模式启动排查历史缓存或启动日志。

也可以运行：

```powershell
.\run.ps1
```

安全模式也可以直接运行：

```powershell
.\run-safe.ps1
```

## 打包 EXE

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean PhotoManageGPT.spec
```

如果打包时报 `PermissionError`，通常是旧的 `PhotoManageGPT.exe` 还在运行。请先关闭软件，必要时在任务管理器中结束 `PhotoManageGPT.exe` 后再打包。

运行发布自检：

```powershell
.\.venv\Scripts\python.exe -m photo_dedupe --release-check
```

发布自检会检查版本号、图标、PyInstaller 配置、README、安全模式启动器、桌面快捷方式脚本、EXE 产物、发布 Manifest、启动烟测配置和发布脚本。`发布 zip` 未生成时只会提醒；真正发布前运行 `.\package.ps1` 即可生成 zip。

生成便携发布包：

```powershell
.\package.ps1
```

发布包会生成到 `release\PhotoManageGPT-v版本号-win64.zip`，旁边会生成 `PhotoManageGPT-v版本号-win64.zip.sha256` 校验文件。zip 里面包含主程序、README、QUICKSTART、CHANGELOG、安全模式启动入口、桌面快捷方式安装/移除脚本和 `RELEASE-MANIFEST.json`。打包过程中会先运行发布目录内 `PhotoManageGPT.exe --startup-smoke-test`，确认主窗口能在安全模式下初始化并退出。Manifest 会记录版本、生成时间、入口文件、安全说明和文件 SHA-256，方便发布后核对。

解压发布包后，如果希望在桌面创建入口，可以右键 `install-shortcut.ps1` 选择“使用 PowerShell 运行”。它会创建普通启动和安全模式两个桌面快捷方式；不再需要时运行 `remove-shortcut.ps1` 只会移除这两个快捷方式，不会删除软件目录或用户文件。

## 当前版本定位

这一版适合作为可推广使用的 Windows 桌面工具基础版：

- 能处理多盘、多目录、大量重复分组。
- 有保护目录和处理确认，降低误操作风险。
- 有扫描历史缓存，减少重复扫描。
- 有 AI API 接入，可继续扩展照片质量判断。
- 仍保持手动确认优先，不做后台常驻监控、不做硬链接替换、不做永久删除。
