# Photo Manage GPT

一个优先适配 Windows 的照片/文件整理去重桌面应用。

## 功能

- 递归扫描一个或多个文件夹。
- 使用“文件大小 + SHA-256”检测完全重复文件。
- 使用图片感知哈希检测视觉相似照片。
- 在重复分组中预览图片和视频。
- 默认不永久删除文件，只把未勾选的重复项移动到独立目录。
- 使用 SQLite 保存扫描记录和移动日志。
- 支持调整图片相似阈值。
- 支持按最高质量、最新修改时间、最大文件自动推荐保留项。
- 支持扫描过程中停止任务。
- 支持查看移动操作记录。
- 支持撤销已移动的重复文件。
- 支持按拍摄年月、拍摄日期、文件类型、相机型号整理文件。
- 支持当前分组的图片缩略图网格。
- 支持保存目标目录、相似阈值、保留策略等设置。
- 支持复用未变化文件的扫描缓存，减少重复计算。
- 视频文件支持预览，完全相同的视频也会通过 SHA-256 精确去重。
- 如果系统安装了 `ffmpeg`，还可以对视频抽帧生成指纹，用于发现相似视频。
- 支持查看扫描历史。
- 支持导出扫描历史和操作记录为 CSV。
- 支持把重复文件移动到 Windows 回收站。
- 支持对接模型厂商 API 做单张图片 AI 质量判断。
- 支持对当前重复分组进行批量 AI 判断。
- 支持按 AI 分数筛选低质量照片。
- 支持导出 AI 判断结果为 CSV。
- 支持自动恢复最近一次扫描得到的重复分组，避免每次重开后重新全量扫描。

## 快速开始

1. 安装 Windows 版 Python 3.10 或更高版本。

2. 创建并激活虚拟环境：

   ```powershell
   py -3.10 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. 安装依赖：

   ```powershell
   pip install -r requirements.txt
   ```

   如果 Windows 上访问 PyPI 出现 SSL 问题，可以使用国内镜像：

   ```powershell
   pip install -r requirements.txt -i http://mirrors.aliyun.com/pypi/simple --trusted-host mirrors.aliyun.com
   ```

4. 启动应用：

   ```powershell
   python -m photo_dedupe
   ```

也可以直接运行：

```powershell
.\run.ps1
```

## 使用方式

1. 点击“添加文件夹”，选择需要整理的照片或文件目录。
2. 根据需要调整“图片相似阈值”。
   - 数值越小，匹配越严格。
   - 数值越大，越容易把相似图片归为一组。
   - 建议先使用默认值 `8`。
3. 选择默认保留策略：
   - 保留最高质量
   - 保留最新修改
   - 保留最大文件
4. 点击“开始扫描”。
5. 在重复分组中查看每组文件。
6. 可以在表格中查看文件详情，也可以点击缩略图快速切换预览。
7. 勾选要保留的文件，取消勾选要移动的重复文件。
8. 选择处理方式：
   - 移动到目标目录
   - 移动到回收站
9. 点击“移动未勾选项”，应用会处理这些重复文件。

## 操作记录与撤销

应用右侧有“操作记录”页，会显示最近的文件移动记录。

如果误移动了文件：

1. 打开“操作记录”页。
2. 选中需要恢复的移动记录。
3. 点击“撤销选中移动”。

如果原路径已经存在同名文件，应用会自动生成安全的新文件名，避免覆盖已有文件。

操作记录也可以导出为 CSV，方便后续审计或人工核对。

移动到 Windows 回收站的记录需要在系统回收站中还原，应用内不会直接撤销这类记录。

## 扫描历史与导出

应用右侧有“扫描历史”页，会显示最近入库的扫描文件记录。

可以点击“导出扫描历史”生成 CSV 文件。CSV 使用 `utf-8-sig` 编码，方便在 Windows Excel 中直接打开。

最近一次扫描得到的重复分组也会单独保存。重新打开应用时，如果存在最近扫描会话，界面会自动恢复这批分组，方便继续处理上次未完成的工作。

如果点击“清空扫描历史”，会同时清空：

- 扫描历史记录
- 文件指纹缓存
- 最近一次保存的重复分组会话

## AI 照片判断

应用右侧有“AI 判断”页，可以配置兼容 OpenAI `chat/completions` 格式的视觉模型 API。

需要填写：

- API 地址，例如 `https://api.example.com/v1`
- 模型名，例如厂商提供的视觉模型名称
- API Key

使用方式：

1. 在“重复处理”页选中一张图片。
2. 打开“AI 判断”页。
3. 选择厂商预设，或使用“自定义”手动填写 API 地址和模型名。
4. 填写并保存 API 配置。
5. 点击“AI 判断当前图片”。

批量分析：

1. 在“重复处理”页选择一个重复分组。
2. 打开“AI 判断”页。
3. 点击“AI 判断当前分组”。

结果筛选：

- 分数筛选框默认为 `100 分及以下`，表示显示所有有分数结果。
- 改为 `60 分及以下` 后，点击“筛选低分”，可以只看低分照片。
- 点击“导出 AI 结果”可以导出 CSV。

分析结果会保存到本机 SQLite 数据库，并显示在 AI 判断结果列表中。

说明：

- API Key 只保存到本机数据库，不会写入源码。
- 当前实现适配 OpenAI-compatible 的 `chat/completions` 图片输入格式。
- 不同厂商的图片输入字段如果不兼容，后续可以增加厂商适配器。

## 视频相似检测

完全相同的视频文件会通过 SHA-256 自动识别，不需要额外工具。

如果希望识别“内容相似但文件不同”的视频，需要安装 `ffmpeg` 并确保命令行能找到：

```powershell
ffmpeg -version
```

启用后，应用会抽取多个视频帧生成感知指纹，并缓存到 SQLite。没有安装 `ffmpeg` 时，应用会自动跳过视频相似检测，不影响其它功能。

## 文件整理规则

添加目录后，可以选择整理规则并点击“执行整理规则”。

当前支持：

- 按拍摄年月
- 按拍摄日期
- 按文件类型
- 按相机型号

按拍摄时间整理时，应用会优先读取图片 EXIF 拍摄时间，并移动到目标目录下：

```text
目标目录/
  2026/
    2026-05/
      photo.jpg
```

如果图片没有 EXIF 拍摄时间，则使用文件修改时间。

## 安全说明

应用不会直接永久删除文件。

移动重复项时，会把文件移动到目标目录，并在本机 SQLite 数据库中记录移动日志。默认目标目录位于桌面下的 `PhotoManageGPT_重复文件` 文件夹。

## 打包

安装 PyInstaller：

```powershell
pip install pyinstaller
```

打包为 Windows 桌面程序：

```powershell
pyinstaller --noconfirm --windowed --name PhotoManageGPT photo_dedupe\__main__.py
```

也可以直接运行项目里的打包脚本：

```powershell
.\build.ps1
```
